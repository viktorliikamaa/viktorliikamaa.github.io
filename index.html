How I work

I act as the architect. I define the problem, design the system and write the specifications and prompts. AI agents like Claude Code handle the implementation, and I review, test and correct until it holds up in real use.

Prove it wrong first

Before I invest in an idea, I try to disprove it with real data. Several of my projects changed direction, or stopped, because the data said so.

Never trust output blindly

AI is confident even when it's wrong. I build in tests, checks and verification steps, and I've caught everything from stale models to invented claims.

Small, tested steps

I build in thin slices, each one tested and committed before the next. I've turned that loop into a reusable agent skill with clear rules for when to stop and ask a human.

Crypto market scanners
Redesigned

Detecting volatility squeezes before the move

Scanners for perpetual futures markets. A post-mortem showed a model that looked better offline traded worse live, because its features were measured after moves had already started. I redesigned it to build a watchlist and wait for a price break.

What it taught me: a good score on paper means little if nobody checks what's actually running.

AdRadar

DeFi research
Concluded
